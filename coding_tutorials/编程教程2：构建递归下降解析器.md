## 第1部分：理解语法和 AST 设计

### 我们正在实现的语法

```
prog   : (expr? ";")*
expr   : term (("+" | "-") term)*     # 加法/减法（较低优先级）
term   : factor (("*" | "/") factor)* # 乘法/除法（较高优先级）  
factor : number | "(" expr ")"        # 数字和括号表达式
```

**关键洞察**：此语法自然编码了操作符优先级！

- `*` 和 `/` 比 `+` 和 `-` 绑定更紧密
- 括号覆盖优先级

### AST 节点设计

首先，让我们设计抽象语法树节点：

```cpp
#pragma once
#include <memory>
#include <vector>
#include "llvm/IR/Value.h"

// 前向声明
class Program;
class Expr;
class BinaryExpr;
class NumberExpr;

// 访问者模式用于遍历 AST（我们稍后详细介绍）
class Visitor {
public:
    virtual ~Visitor() {}
    virtual llvm::Value* VisitProgram(Program* p) = 0;
    virtual llvm::Value* VisitBinaryExpr(BinaryExpr* expr) = 0;
    virtual llvm::Value* VisitNumberExpr(NumberExpr* expr) = 0;
};

// 所有表达式的基类
class Expr {
public:
    virtual ~Expr() {}
    virtual llvm::Value* Accept(Visitor* v) = 0;
};

// 操作符类型
enum class OpCode {
    Add,    // +
    Sub,    // -
    Mul,    // *
    Div     // /
};

// 二元表达式：left op right（例如，"5 + 3"）
class BinaryExpr : public Expr {
public:
    OpCode op;
    std::shared_ptr<Expr> left;
    std::shared_ptr<Expr> right;
    
    llvm::Value* Accept(Visitor* v) override {
        return v->VisitBinaryExpr(this);
    }
};

// 数字字面量：42, 123, 等等
class NumberExpr : public Expr {
public:
    int value;
    
    NumberExpr(int val) : value(val) {}
    
    llvm::Value* Accept(Visitor* v) override {
        return v->VisitNumberExpr(this);
    }
};

// 程序：表达式集合
class Program {
public:
    std::vector<std::shared_ptr<Expr>> expressions;
};
```

bool Parser::Expect(TokenType type) {

    if (currentToken.tokenType == type) {

### 步骤2：ParseProgram（顶层）

```cpp
std::shared_ptr<Program> Parser::ParseProgram() {
    auto program = std::make_shared<Program>();
    
    // 持续解析直到文件结束
    while (!Expect(TokenType::eof)) {
        
        // 处理空语句（只有分号）
        if (Expect(TokenType::semi)) {
            Advance();  // 跳过分号
            continue;
        }
        
        // 解析表达式
        auto expr = ParseExpr();
        if (expr) {
            program->expressions.push_back(expr);
        }
        
        // 期望表达式后的分号（目前可选）
        if (Expect(TokenType::semi)) {
            Advance();
        }
    }
    
    return program;
}
```

### 步骤3：ParseFactor（解析树的叶子）

从语法的**底部**开始 - 最简单的元素：

```cpp
std::shared_ptr<Expr> Parser::ParseFactor() {
    // factor : number | "(" expr ")"
    
    if (Expect(TokenType::number)) {
        // 它是数字字面量
        int value = currentToken.value;
        Advance();  // 消费数字标记
        
        return std::make_shared<NumberExpr>(value);
        
    } else if (Expect(TokenType::l_parent)) {
        // 它是括号表达式："(" expr ")"
        Advance();  // 消费 '('
        
        auto expr = ParseExpr();  // 递归解析内部表达式
        
        if (!Consume(TokenType::r_parent)) {
            ReportError("Expected ')' after expression");
            return nullptr;
        }
        
        return expr;
        
    } else {
        ReportError("Expected number or '(' in expression");
        return nullptr;
    }
}
```

**工作原理：**

- 数字变成 `NumberExpr` 节点
- `(expr)` 解析内部表达式并返回它（括号只是分组，不创建节点）

### 步骤4：ParseTerm（乘法和除法）

```cpp
std::shared_ptr<Expr> Parser::ParseTerm() {
    // term : factor (("*" | "/") factor)*
    
    // 解析第一个因子
    auto left = ParseFactor();
    if (!left) return nullptr;
    
    // 处理任意数量的 * 或 / 操作符（左结合）
    while (Expect(TokenType::star) || Expect(TokenType::slash)) {
        
        // 确定操作符
        OpCode op;
        if (Expect(TokenType::star)) {
            op = OpCode::Mul;
        } else {  // 必须是 slash
            op = OpCode::Div;
        }
        
        Advance();  // 消费操作符标记
        
        // 解析右操作数
        auto right = ParseFactor();
        if (!right) return nullptr;
        
        // 创建二元表达式节点
        auto binaryExpr = std::make_shared<BinaryExpr>();
        binaryExpr->op = op;
        binaryExpr->left = left;
        binaryExpr->right = right;
        
        // 这成为潜在下一个操作符的新左操作数
        left = binaryExpr;
    }
    
    return left;
}
```

**左结合性示例：** 输入：`2 * 3 * 4`

**逐步执行：**

1. `left = ParseFactor()` → `NumberExpr(2)`
2. 看到 `*`，创建 `BinaryExpr(2 * 3)`，`left = BinaryExpr(2 * 3)`
3. 看到 `*`，创建 `BinaryExpr((2 * 3) * 4)`，`left = BinaryExpr((2 * 3) * 4)`

**结果 AST：**

```
     *
   /   \
  *     4
 / \
2   3
```

这正确表示了左结合求值：`(2 * 3) * 4`。

### 步骤5：ParseExpr（加法和减法）

```cpp
std::shared_ptr<Expr> Parser::ParseExpr() {
    // expr : term (("+" | "-") term)*
    
    // 解析第一个项
    auto left = ParseTerm();
    if (!left) return nullptr;
    
    // 处理任意数量的 + 或 - 操作符（左结合）
    while (Expect(TokenType::plus) || Expect(TokenType::minus)) {
        
        // 确定操作符
        OpCode op;
        if (Expect(TokenType::plus)) {
            op = OpCode::Add;
        } else {  // 必须是 minus
            op = OpCode::Sub;
        }
        
        Advance();  // 消费操作符标记
        
        // 解析右操作数
        auto right = ParseTerm();
        if (!right) return nullptr;
        
        // 创建二元表达式节点
        auto binaryExpr = std::make_shared<BinaryExpr>();
        binaryExpr->op = op;
        binaryExpr->left = left;
        binaryExpr->right = right;
        
        // 这成为潜在下一个操作符的新左操作数
        left = binaryExpr;
    }
    
    return left;
}
```

## 第4部分：通过语法理解操作符优先级

让我们跟踪解析 `2 + 3 * 4`：

### 调用栈跟踪：

```cpp
ParseExpr()                    // 入口点
├── ParseTerm()                // 解析 "2"
│   └── ParseFactor() → 2      // 返回 NumberExpr(2)
├── 看到 '+'，消费它
├── ParseTerm()                // 解析 "3 * 4"
│   ├── ParseFactor() → 3      // 返回 NumberExpr(3)
│   ├── 看到 '*'，消费它
│   ├── ParseFactor() → 4      // 返回 NumberExpr(4)
│   └── 返回 BinaryExpr(3 * 4)  // 乘法首先发生！
└── 返回 BinaryExpr(2 + (3 * 4))  // 加法在顶层
```

**结果 AST：**

```
     +
   /   \
  2     *
       / \
      3   4
```

**为什么这有效：**

- `ParseTerm()` 在返回到 `ParseExpr()` 之前处理 `*` 和 `/`
- 这迫使乘法比加法绑定更紧密
- 语法结构**自动**处理优先级！

## 第5部分：高级解析技术

### 错误恢复

```cpp
std::shared_ptr<Expr> Parser::ParseFactor() {
    if (Expect(TokenType::number)) {
        int value = currentToken.value;
        Advance();
        return std::make_shared<NumberExpr>(value);
        
    } else if (Expect(TokenType::l_parent)) {
        Advance();
        auto expr = ParseExpr();
        
        if (!Consume(TokenType::r_parent)) {
            ReportError("Expected ')' after expression");
            
            // 错误恢复：跳过标记直到找到 ')' 或 ';'
            while (!Expect(TokenType::eof) && 
                   !Expect(TokenType::r_parent) && 
                   !Expect(TokenType::semi)) {
                Advance();
            }
            
            if (Expect(TokenType::r_parent)) {
                Advance();  // 消费 ')'
            }
        }
        
        return expr;
        
    } else {
        ReportError("Expected number or '(' in expression");
        
        // 错误恢复：创建虚拟节点以继续解析
        return std::make_shared<NumberExpr>(0);  // 虚拟值
    }
}
```

### 添加一元操作符

让我们扩展语法以处理一元减号：

```
factor : number | "(" expr ")" | "-" factor | "+" factor
std::shared_ptr<Expr> Parser::ParseFactor() {
    if (Expect(TokenType::number)) {
        int value = currentToken.value;
        Advance();
        return std::make_shared<NumberExpr>(value);
        
    } else if (Expect(TokenType::l_parent)) {
        Advance();
        auto expr = ParseExpr();
        if (!Consume(TokenType::r_parent)) {
            ReportError("Expected ')' after expression");
        }
        return expr;
        
    } else if (Expect(TokenType::minus)) {
        // 一元减号：-factor
        Advance();  // 消费 '-'
        auto operand = ParseFactor();  // 递归解析操作数
        
        // 创建一元表达式节点
        auto unaryExpr = std::make_shared<UnaryExpr>();
        unaryExpr->op = UnaryOpCode::Neg;
        unaryExpr->operand = operand;
        return unaryExpr;
        
    } else if (Expect(TokenType::plus)) {
        // 一元加号：+factor（只返回因子）
        Advance();  // 消费 '+'
        return ParseFactor();
        
    } else {
        ReportError("Expected number, '(', '+', or '-' in expression");
        return std::make_shared<NumberExpr>(0);  // 错误恢复
    }
}
```

### 添加更多带优先级的操作符

让我们添加比较操作符（`<`, `>`, `==`, `!=`）：

```
expr       : comparison
comparison : term (("==" | "!=" | "<" | ">") term)*
term       : factor (("*" | "/") factor)*
factor     : number | "(" expr ")" | "-" factor | "+" factor
std::shared_ptr<Expr> Parser::ParseExpr() {
    // 现在只委托给比较
    return ParseComparison();
}

std::shared_ptr<Expr> Parser::ParseComparison() {
    auto left = ParseTerm();
    if (!left) return nullptr;
    
    while (Expect(TokenType::equal_equal) || Expect(TokenType::not_equal) ||
           Expect(TokenType::less) || Expect(TokenType::greater)) {
        
        OpCode op;
        if (Expect(TokenType::equal_equal)) {
            op = OpCode::Equal;
        } else if (Expect(TokenType::not_equal)) {
            op = OpCode::NotEqual;
        } else if (Expect(TokenType::less)) {
            op = OpCode::Less;
        } else {  // greater
            op = OpCode::Greater;
        }
        
        Advance();
        auto right = ParseTerm();
        if (!right) return nullptr;
        
        auto binaryExpr = std::make_shared<BinaryExpr>();
        binaryExpr->op = op;
        binaryExpr->left = left;
        binaryExpr->right = right;
        
        left = binaryExpr;
    }
    
    return left;
}
```

### 创建 AST 打印器（调试工具）

```cpp
class ASTPrinter : public Visitor {
public:
    llvm::Value* VisitProgram(Program* p) override {
        std::cout << "Program with " << p->expressions.size() << " expressions:\n";
        for (auto& expr : p->expressions) {
            expr->Accept(this);
            std::cout << "\n";
        }
        return nullptr;
    }
    
    llvm::Value* VisitBinaryExpr(BinaryExpr* expr) override {
        std::cout << "(";
        expr->left->Accept(this);
        
        switch (expr->op) {
        case OpCode::Add: std::cout << " + "; break;
        case OpCode::Sub: std::cout << " - "; break;
        case OpCode::Mul: std::cout << " * "; break;
        case OpCode::Div: std::cout << " / "; break;
        }
        
        expr->right->Accept(this);
        std::cout << ")";
        return nullptr;
    }
    
    llvm::Value* VisitNumberExpr(NumberExpr* expr) override {
        std::cout << expr->value;
        return nullptr;
    }
};

// 用法：
void TestParserWithPrinting() {
    std::string input = "2 + 3 * 4;";
    Lexer lexer(llvm::StringRef(input));
    Parser parser(lexer);
    auto program = parser.ParseProgram();
    
    ASTPrinter printer;
    program->expressions[0]->Accept(&printer);
    // 输出：(2 + (3 * 4))
}
```

#include "lexer.h"

        return 1;
    }
    
    return 0;

## 第8部分：常见解析陷阱和解决方案

### 问题1：左递归

**不要这样做：**

```
expr : expr "+" term | term
```

这会导致无限递归！解析器调用 `ParseExpr()` 立即又调用 `ParseExpr()`。

**解决方案：转换为右递归加迭代：**

```
expr : term ("+" term)*
```

### 问题2：优先级错误

**错误方法：**

```cpp
// 这给 + 比 * 更高的优先级！
std::shared_ptr<Expr> Parser::ParseExpr() {
    auto left = ParseFactor();  // 跳过 term 级别！
    // ... 处理 + 和 -
}
```

**正确方法：**

- 总是调用**下一个更高优先级**级别
- `ParseExpr()` 调用 `ParseTerm()` 调用 `ParseFactor()`

### 问题3：错误恢复

```cpp
// 坏：解析器在第一个错误时停止
if (!Consume(TokenType::semi)) {
    return nullptr;  // 完全放弃
}

// 更好：尝试恢复并继续
if (!Consume(TokenType::semi)) {
    ReportError("Expected ';'");
    // 跳到下一个语句
    while (!Expect(TokenType::eof) && !Expect(TokenType::semi)) {
        Advance();
    }
    if (Expect(TokenType::semi)) {
        Advance();
    }
}
```
