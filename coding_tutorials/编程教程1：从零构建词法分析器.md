## 第1部分：理解词法分析器接口

### Token 类 - 您的数据结构

首先，让我们理解什么是标记（token）以及如何表示它：

```cpp
#pragma once
#include "llvm/ADT/StringRef.h"
#include "llvm/Support/raw_ostream.h"

// 我们语言中所有可能的标记类型
enum class TokenType : uint8_t {
    // 字面量
    number,           // 42, 123
    identifier,       // 变量名, 函数名
    
    // 关键字  
    kw_int,          // int
    kw_if,           // if
    kw_else,         // else
    kw_for,          // for
    kw_return,       // return
    
    // 单字符操作符
    plus,            // +
    minus,           // -
    star,            // *
    slash,           // /
    equal,           // =
    l_parent,        // (
    r_parent,        // )
    l_brace,         // {
    r_brace,         // }
    semi,            // ;
    comma,           // ,
    
    // 多字符操作符
    equal_equal,     // ==
    not_equal,       // !=
    less_equal,      // <=
    greater_equal,   // >=
    plus_plus,       // ++
    minus_minus,     // --
    
    // 特殊
    eof,             // 文件结束
    unknown          // 错误情况
};

class Token {
public:
    // 此标记在源代码中出现的位置
    int row, col;
    
    // 此标记的类型
    TokenType tokenType;
    
    // 对于数字：实际的数值
    int value;
    
    // 源代码中的实际文本
    llvm::StringRef content;
    
    // 构造函数
    Token() : row(-1), col(-1), tokenType(TokenType::unknown), value(-1) {}
    
    // 调试输出
    void Dump() const {
        llvm::outs() << "Token{type=" << (int)tokenType 
                     << ", content=\"" << content 
                     << "\", row=" << row 
                     << ", col=" << col 
                     << "}\n";
    }
};
```

### Lexer 类 - 您的状态机

```cpp
class Lexer {
```

## 第2部分：逐步实现词法分析器

### 步骤1：构造函数和基本设置

```cpp
#include "lexer.h"

// 辅助函数 - 这些将在整个过程中使用
bool Lexer::IsDigit(char ch) {
    return (ch >= '0' && ch <= '9');
}

bool Lexer::IsAlpha(char ch) {
    return (ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z') || ch == '_';
}

bool Lexer::IsAlnum(char ch) {
    return IsAlpha(ch) || IsDigit(ch);
}

// 构造函数：设置初始状态
Lexer::Lexer(llvm::StringRef sourceCode) {
    BufPtr = sourceCode.begin();    // 从开始位置开始
    BufEnd = sourceCode.end();      // 记住停止位置
    LineHeadPtr = sourceCode.begin(); // 跟踪行开始位置以计算列数
    row = 1;                        // 从第1行开始
}
```

### 步骤2：空白字符处理

```cpp
void Lexer::SkipWhitespace() {
    while (BufPtr < BufEnd) {
        char ch = *BufPtr;
        
        if (ch == ' ' || ch == '\t' || ch == '\r') {
            // 跳过常规空白字符
            BufPtr++;
        } else if (ch == '\n') {
            // 新行：增加行号，更新行头
            row++;
            BufPtr++;
            LineHeadPtr = BufPtr;  // 下一行从这里开始
        } else {
            // 不是空白字符，停止跳过
            break;
        }
    }
}
```

### 步骤3：数字词法分析（完整实现）

```cpp
void Lexer::LexNumber(Token &tok) {
    const char *start = BufPtr;  // 记住数字开始位置
    int number = 0;
    int len = 0;
    
    // 读取所有连续的数字
    while (BufPtr < BufEnd && IsDigit(*BufPtr)) {
        number = number * 10 + (*BufPtr - '0');  // 将字符转换为数字
        BufPtr++;
        len++;
    }
    
    // 填充标记信息
    tok.tokenType = TokenType::number;
    tok.value = number;
    tok.content = llvm::StringRef(start, len);
}
```

**工作原理：**

- `*BufPtr - '0'` 将 ASCII 数字转换为数值（'0' = 48, '1' = 49，所以 '1' - '0' = 1）
- `number * 10 + digit` 从左到右构建数字（123 = ((1*10 + 2)*10 + 3)）
- `StringRef(start, len)` 捕获源代码中的确切文本

### 步骤4：标识符和关键字词法分析

```cpp
void Lexer::LexIdentifier(Token &tok) {
    const char *start = BufPtr;
    
    // 第一个字符必须是字母或下划线
    if (!IsAlpha(*BufPtr)) {
        tok.tokenType = TokenType::unknown;
        return;
    }
    
    // 读取字母、数字、下划线
    while (BufPtr < BufEnd && IsAlnum(*BufPtr)) {
        BufPtr++;
    }
    
    int len = BufPtr - start;
    tok.content = llvm::StringRef(start, len);
    
    // 检查此标识符是否实际上是关键字
    if (tok.content == "int") {
        tok.tokenType = TokenType::kw_int;
    } else if (tok.content == "if") {
        tok.tokenType = TokenType::kw_if;
    } else if (tok.content == "else") {
        tok.tokenType = TokenType::kw_else;
    } else if (tok.content == "for") {
        tok.tokenType = TokenType::kw_for;
    } else if (tok.content == "return") {
        tok.tokenType = TokenType::kw_return;
    } else {
        // 不是关键字，它是标识符
        tok.tokenType = TokenType::identifier;
    }
}
```

**高级关键字查找（更高效）：**

```cpp
#include <unordered_map>

class Lexer {
private:
    // 静态关键字映射 - 只初始化一次
    static std::unordered_map<std::string, TokenType> keywords;
    
public:
    static void InitializeKeywords() {
        if (keywords.empty()) {
            keywords["int"] = TokenType::kw_int;
            keywords["if"] = TokenType::kw_if;
            keywords["else"] = TokenType::kw_else;
            keywords["for"] = TokenType::kw_for;
            keywords["while"] = TokenType::kw_while;
            keywords["return"] = TokenType::kw_return;
            keywords["break"] = TokenType::kw_break;
            keywords["continue"] = TokenType::kw_continue;
            keywords["sizeof"] = TokenType::kw_sizeof;
            keywords["struct"] = TokenType::kw_struct;
            keywords["union"] = TokenType::kw_union;
            keywords["typedef"] = TokenType::kw_typedef;
            keywords["const"] = TokenType::kw_const;
        }
    }
};

void Lexer::LexIdentifier(Token &tok) {
    const char *start = BufPtr;
    
    // 读取标识符字符
    while (BufPtr < BufEnd && IsAlnum(*BufPtr)) {
        BufPtr++;
    }
    
    int len = BufPtr - start;
    tok.content = llvm::StringRef(start, len);
    
    // 在关键字表中查找
    std::string str(tok.content.str());
    auto it = keywords.find(str);
    if (it != keywords.end()) {
        tok.tokenType = it->second;  // 它是关键字
    } else {
        tok.tokenType = TokenType::identifier;  // 它是标识符
    }
}
```

### 步骤5：操作符词法分析（复杂部分！）

这是变得有趣的地方。我们需要处理单字符（`+`, `-`）和多字符（`++`, `==`, `<=`）操作符：

```cpp
void Lexer::LexOperator(Token &tok) {
    const char *start = BufPtr;
    char ch = *BufPtr++;  // 读取当前字符并前进
    
    // 这是棘手的部分 - 我们需要向前看多字符操作符
    switch (ch) {
    case '+':
        if (BufPtr < BufEnd && *BufPtr == '+') {
            BufPtr++;  // 消费第二个 '+'
            tok.tokenType = TokenType::plus_plus;
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::plus;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '-':
        if (BufPtr < BufEnd && *BufPtr == '-') {
            BufPtr++;  // 消费第二个 '-'
            tok.tokenType = TokenType::minus_minus;
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::minus;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '=':
        if (BufPtr < BufEnd && *BufPtr == '=') {
            BufPtr++;  // 消费第二个 '='
            tok.tokenType = TokenType::equal_equal;
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::equal;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '<':
        if (BufPtr < BufEnd && *BufPtr == '=') {
            BufPtr++;
            tok.tokenType = TokenType::less_equal;
            tok.content = llvm::StringRef(start, 2);
        } else if (BufPtr < BufEnd && *BufPtr == '<') {
            BufPtr++;
            tok.tokenType = TokenType::less_less;  // << (左移)
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::less;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '>':
        if (BufPtr < BufEnd && *BufPtr == '=') {
            BufPtr++;
            tok.tokenType = TokenType::greater_equal;
            tok.content = llvm::StringRef(start, 2);
        } else if (BufPtr < BufEnd && *BufPtr == '>') {
            BufPtr++;
            tok.tokenType = TokenType::greater_greater;  // >> (右移)
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::greater;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '!':
        if (BufPtr < BufEnd && *BufPtr == '=') {
            BufPtr++;
            tok.tokenType = TokenType::not_equal;
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::exclaim;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '&':
        if (BufPtr < BufEnd && *BufPtr == '&') {
            BufPtr++;
            tok.tokenType = TokenType::ampamp;  // && (逻辑与)
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::amp;      // & (按位与)
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    case '|':
        if (BufPtr < BufEnd && *BufPtr == '|') {
            BufPtr++;
            tok.tokenType = TokenType::pipepipe;  // || (逻辑或)
            tok.content = llvm::StringRef(start, 2);
        } else {
            tok.tokenType = TokenType::pipe;      // | (按位或)
            tok.content = llvm::StringRef(start, 1);
        }
        break;
        
    // 简单的单字符操作符
    case '*':
        tok.tokenType = TokenType::star;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '/':
        tok.tokenType = TokenType::slash;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '%':
        tok.tokenType = TokenType::percent;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '(':
        tok.tokenType = TokenType::l_parent;
        tok.content = llvm::StringRef(start, 1);
        break;
    case ')':
        tok.tokenType = TokenType::r_parent;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '{':
        tok.tokenType = TokenType::l_brace;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '}':
        tok.tokenType = TokenType::r_brace;
        tok.content = llvm::StringRef(start, 1);
        break;
    case ';':
        tok.tokenType = TokenType::semi;
        tok.content = llvm::StringRef(start, 1);
        break;
    case ',':
        tok.tokenType = TokenType::comma;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '^':
        tok.tokenType = TokenType::caret;
        tok.content = llvm::StringRef(start, 1);
        break;
    case '~':
        tok.tokenType = TokenType::tilde;
        tok.content = llvm::StringRef(start, 1);
        break;
        
    default:
        // 未知字符
        tok.tokenType = TokenType::unknown;
        tok.content = llvm::StringRef(start, 1);
        break;
    }
}
```

### 步骤6：主要的 NextToken 方法（将所有内容整合在一起）

```cpp
void Lexer::NextToken(Token &tok) {
    // 步骤1：跳过任何空白字符
    SkipWhitespace();
    
    // 步骤2：记录此标记的当前位置
    tok.row = row;
    tok.col = BufPtr - LineHeadPtr + 1;  // 列号（从1开始）
    
    // 步骤3：检查文件结束
    if (BufPtr >= BufEnd) {
        tok.tokenType = TokenType::eof;
        tok.content = llvm::StringRef("");
        return;
    }
    
    // 步骤4：查看当前字符并决定要做什么
    char ch = *BufPtr;
    
    if (IsDigit(ch)) {
        // 它是数字
        LexNumber(tok);
    } else if (IsAlpha(ch)) {
        // 它是标识符或关键字
        LexIdentifier(tok);
    } else {
        // 它是操作符或标点
        LexOperator(tok);
    }
}
```

```cpp
void Lexer::LexString(Token &tok) {
    const char *start = BufPtr;
    BufPtr++;  // 跳过开始引号
    
    std::string stringValue;
    
    while (BufPtr < BufEnd && *BufPtr != '"') {
        if (*BufPtr == '\\') {
            // 处理转义序列
            BufPtr++;
            if (BufPtr >= BufEnd) break;
            
            switch (*BufPtr) {
            case 'n': stringValue += '\n'; break;
            case 't': stringValue += '\t'; break;
            case 'r': stringValue += '\r'; break;
            case '\\': stringValue += '\\'; break;
            case '"': stringValue += '"'; break;
            case '0': stringValue += '\0'; break;
            default:
                // 未知转义序列 - 只是按字面意思包含
                stringValue += *BufPtr;
                break;
            }
        } else {
            stringValue += *BufPtr;
        }
        BufPtr++;
    }
    
    if (BufPtr < BufEnd && *BufPtr == '"') {
        BufPtr++;  // 跳过结束引号
        tok.tokenType = TokenType::str;
        tok.content = llvm::StringRef(start, BufPtr - start);
        // 将实际字符串值存储在某处（可能在 Token 类中）
    } else {
        // 未终止的字符串
        tok.tokenType = TokenType::unknown;
        tok.content = llvm::StringRef(start, BufPtr - start);
    }
}
```

### 注释处理

```cpp
void Lexer::SkipLineComment() {
    // 跳过直到行末
    while (BufPtr < BufEnd && *BufPtr != '\n') {
        BufPtr++;
    }
    // 不要跳过换行符 - 让 SkipWhitespace 处理它
}

void Lexer::SkipBlockComment() {
    BufPtr += 2;  // 跳过 /*
    
    while (BufPtr + 1 < BufEnd) {
        if (*BufPtr == '*' && *(BufPtr + 1) == '/') {
            BufPtr += 2;  // 跳过 */
            return;
        }
        if (*BufPtr == '\n') {
            row++;
            LineHeadPtr = BufPtr + 1;
        }
        BufPtr++;
    }
    // 未终止的块注释 - 应该报告错误
}

// 修改 LexOperator 以处理注释
void Lexer::LexOperator(Token &tok) {
    const char *start = BufPtr;
    char ch = *BufPtr++;
    
    switch (ch) {
    case '/':
        if (BufPtr < BufEnd && *BufPtr == '/') {
            // 行注释
            SkipLineComment();
            NextToken(tok);  // 获取注释后的下一个标记
            return;
        } else if (BufPtr < BufEnd && *BufPtr == '*') {
            // 块注释
            SkipBlockComment();
            NextToken(tok);  // 获取注释后的下一个标记
            return;
        } else {
            tok.tokenType = TokenType::slash;
            tok.content = llvm::StringRef(start, 1);
        }
        break;
    // ... 其余情况
    }
}
```

## 第5部分：与解析器集成

您的词法分析器需要与解析器无缝协作。以下是如何创建接口：

```cpp
class Parser {
private:
    Lexer& lexer;
    Token currentToken;
    
public:
    Parser(Lexer& lex) : lexer(lex) {
        // 获取第一个标记
        lexer.NextToken(currentToken);
    }
    
    void ConsumeToken() {
        lexer.NextToken(currentToken);
    }
    
    bool IsToken(TokenType type) {
        return currentToken.tokenType == type;
    }
    
    bool ConsumeToken(TokenType expected) {
        if (currentToken.tokenType == expected) {
            ConsumeToken();
            return true;
        }
        return false;  // 错误：意外的标记
    }
};
```
